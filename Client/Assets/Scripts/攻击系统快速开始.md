# 攻击系统快速开始指南

## 🎯 5分钟快速上手

### 1️⃣ 基础攻击（最简单）

**创建步骤：**
1. 在 Unity Editor 中：`右键 → Create → Quantum → Attack Ability Data`
2. 命名为 `LightPunch`
3. 配置参数：

```
BaseDamage: 10
KnockbackForce: 3
HitstunDuration: 0.2
AttackShape:
  - ShapeType: Box
  - BoxExtents: (0.5, 0.5)
  - PositionOffset: (0.5, 0)
```

✅ 完成！这就是一个基础的轻拳攻击。

---

### 2️⃣ 三连击（中等难度）

**创建步骤：**
1. 创建 C# 脚本使用 `ComboAttackAbilityData`（或在 Unity 中创建 ScriptableObject）
2. 配置参数：

```
MaxComboCount: 3
ComboWindow: 0.5
ComboDamageMultipliers: [1.0, 1.2, 1.5]
ComboDurations: [0.33, 0.4, 0.5]
ComboKnockbackForces: [3, 4, 8]
LastHitLaunches: true
LastHitVerticalKnockback: 2.0
```

✅ 这样就有了一个 AAA 三连击！

---

### 3️⃣ 波动拳（指令技）

**创建步骤：**
1. 使用 `CommandAttackAbilityData`
2. 配置参数：

```
InputSequence: [2, 3, 6, 1]  // ↓↘→ + 拳
EnergyCost: 25
SpecialDamageMultiplier: 2.0
SpawnsProjectile: true
ProjectileSpeed: 10
ProjectileLifetime: 2.0
InvincibilityFrames: 0.1
```

✅ 现在有了经典的波动拳！

## 🎮 代码集成示例

### 在能力系统中使用

```csharp
// 在您的 AbilityInputSystem 或类似系统中
public unsafe class AttackInputSystem : SystemMainThreadFilter<AttackInputSystem.Filter>
{
    public struct Filter
    {
        public EntityRef Entity;
        public PlayerStatus* PlayerStatus;
        public AbilityInventory* AbilityInventory;
        public Input* Input;
    }

    public override void Update(Frame f, ref Filter filter)
    {
        // 轻拳攻击
        if (filter.Input->LightPunch.WasPressed)
        {
            // 激活轻拳能力
            AbilityType abilityType = AbilityType.LightPunch;
            f.Signals.OnAbilityInputReceived(filter.Entity, abilityType);
        }

        // 重拳攻击
        if (filter.Input->HeavyPunch.WasPressed)
        {
            AbilityType abilityType = AbilityType.HeavyPunch;
            f.Signals.OnAbilityInputReceived(filter.Entity, abilityType);
        }
    }
}
```

## 🐛 常见问题排查

### 问题 1：攻击没有命中

✅ **检查清单：**
- [ ] `GameSettingsData.PlayerLayerMask` 是否正确配置
- [ ] 目标实体是否在正确的 Layer 上
- [ ] `AttackShape` 的范围是否足够大
- [ ] `Transform2D` 的位置是否正确

### 问题 2：重复命中同一个目标

✅ **检查：**
- [ ] 是否使用了 `_hitEntities` HashSet
- [ ] 是否在循环结束后调用了 `_hitEntities.Clear()`

### 问题 3：格挡没有生效

✅ **检查：**
- [ ] `AbilityInventory.IsBlocking` 是否正确设置
- [ ] 是否触发了 `OnPlayerBlockHit` 事件

### 问题 4：连击不工作

✅ **检查：**
- [ ] `AttackData.ComboCounter` 是否存在
- [ ] `ComboWindow` 时间是否足够长
- [ ] 输入间隔是否在窗口内
