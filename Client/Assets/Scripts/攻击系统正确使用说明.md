# 攻击系统使用说明（Quantum 官方模式）

## ⚠️ 重要 - 基于官方代码模式

本系统完全基于 Quantum 官方推荐的攻击实现模式：

### 官方模式的关键点：

1. **正确的 Physics2D API**
```csharp
// ✅ 正确
HitCollection2D hits = frame.Physics2D.OverlapShape(
    transform->Position, 
    transform->Rotation, 
    shape, 
    layerMask, 
    QueryOptions.HitKinematics
);

// ❌ 错误 - 不要使用这种方式
var hitFilter = frame.Physics2D.OverlapShape(position, rotation, &shape);
```

2. **防重复命中机制**
```csharp
private static HashSet<EntityRef> _hitEntities = new HashSet<EntityRef>();

// 在检测开始时添加攻击者
_hitEntities.Add(entityRef);

// 检查每个被击中的实体
if (_hitEntities.Contains(hit.Entity))
{
    continue;  // 跳过已经命中的实体
}
_hitEntities.Add(hit.Entity);

// 结束时清空
_hitEntities.Clear();
```

3. **正确的方法签名**
```csharp
// ✅ 正确
public override unsafe bool TryActivateAbility(
    Frame frame, 
    EntityRef entityRef, 
    PlayerStatus* playerStatus, 
    ref Ability ability)

// ❌ 错误
public override bool TryActivateAbility(
    Frame frame, 
    EntityRef entityRef, 
    PlayerLink* playerLink, 
    AbilityType abilityType, 
    ref Ability ability)
```

4. **在正确的时机执行判定**
```csharp
public override Ability.AbilityState UpdateAbility(...)
{
    Ability.AbilityState abilityState = base.UpdateAbility(...);

    // ✅ 在激活的第一帧执行判定
    if (abilityState.IsActiveStartTick)
    {
        OnAttackActivate(frame, entityRef, ref ability);
    }

    return abilityState;
}
```

## 完整代码示例

### AttackAbilityData - 基础攻击类

```csharp
[Serializable]
public unsafe partial class AttackAbilityData : AbilityData
{
    public Shape2DConfig AttackShape;
    public StatusEffectConfig[] HitStatusEffects;
    public FP BaseDamage = 10;
    public FP KnockbackForce = 5;
    public FP HitstunDuration = FP._0_25;

    // 防重复命中的静态集合
    private static HashSet<EntityRef> _hitEntities = new HashSet<EntityRef>();

    public override Ability.AbilityState UpdateAbility(
        Frame frame, 
        EntityRef entityRef, 
        ref Ability ability)
    {
        Ability.AbilityState abilityState = base.UpdateAbility(frame, entityRef, ref ability);

        if (abilityState.IsActiveStartTick)
        {
            OnAttackActivate(frame, entityRef, ref ability);
        }

        return abilityState;
    }

    protected virtual void OnAttackActivate(
        Frame frame, 
        EntityRef entityRef, 
        ref Ability ability)
    {
        PlayerStatus* playerStatus = frame.Unsafe.GetPointer<PlayerStatus>(entityRef);
        Transform2D* transform = frame.Unsafe.GetPointer<Transform2D>(entityRef);
        GameSettingsData settings = frame.FindAsset<GameSettingsData>(
            frame.RuntimeConfig.GameSettingsData.Id
        );

        // 创建攻击形状
        var shape = AttackShape.CreateShape(frame);
        
        // 执行碰撞检测 - Quantum 官方 API
        HitCollection2D hits = frame.Physics2D.OverlapShape(
            transform->Position,
            transform->Rotation,
            shape,
            settings.PlayerLayerMask,
            QueryOptions.HitKinematics
        );

        if (hits.Count > 0)
        {
            // 添加攻击者到集合
            _hitEntities.Add(entityRef);

            for (int i = 0; i < hits.Count; i++)
            {
                Hit2D hit = hits[i];

                // 检查是否已经命中
                if (_hitEntities.Contains(hit.Entity))
                {
                    continue;
                }

                _hitEntities.Add(hit.Entity);

                // 检查队伍
                PlayerStatus* hitPlayerStatus = frame.Unsafe.GetPointer<PlayerStatus>(hit.Entity);
                if (playerStatus->PlayerTeam == hitPlayerStatus->PlayerTeam)
                {
                    continue;
                }

                // 计算命中方向
                Transform2D* hitTransform = frame.Unsafe.GetPointer<Transform2D>(hit.Entity);
                FPVector2 hitDirection = hitTransform->Position - transform->Position;
                hitDirection = hitDirection.Normalized;

                // 检查格挡
                AbilityInventory* hitAbilityInventory = frame.Unsafe.GetPointer<AbilityInventory>(hit.Entity);
                if (hitAbilityInventory->IsBlocking)
                {
                    frame.Events.OnPlayerBlockHit(hit.Entity, hitDirection);
                }
                else
                {
                    // 应用攻击效果
                    ApplyDamage(frame, entityRef, hit.Entity);
                    ApplyKnockback(frame, entityRef, hit.Entity, hitDirection);
                    ApplyStatusEffects(frame, hit.Entity, hitDirection);
                    
                    frame.Events.OnPlayerHit(hit.Entity);
                }
            }

            // 清空防重复命中集合
            _hitEntities.Clear();
        }
    }

    public override unsafe bool TryActivateAbility(
        Frame frame, 
        EntityRef entityRef, 
        PlayerStatus* playerStatus, 
        ref Ability ability)
    {
        bool activated = base.TryActivateAbility(frame, entityRef, playerStatus, ref ability);

        if (activated)
        {
            frame.Events.OnPlayerAttacked(entityRef);
        }

        return activated;
    }

    protected virtual void ApplyDamage(Frame frame, EntityRef attacker, EntityRef target)
    {
        FP damage = CalculateDamage(frame, attacker);
        
        if (frame.Unsafe.TryGetPointer<Health>(target, out var health))
        {
            health->CurrentHealth -= damage;
            
            if (health->CurrentHealth <= 0)
            {
                frame.Events.EntityDied(target, attacker);
            }
        }
    }

    protected virtual void ApplyKnockback(
        Frame frame, 
        EntityRef attacker, 
        EntityRef target, 
        FPVector2 hitDirection)
    {
        if (KnockbackForce <= 0) return;

        FPVector3 knockbackDirection3D = new FPVector3(
            hitDirection.X, 
            hitDirection.Y, 
            FP._0
        );
        
        frame.Signals.OnKnockbackApplied(
            target, 
            HitstunDuration, 
            knockbackDirection3D * KnockbackForce
        );
    }

    protected virtual void ApplyStatusEffects(
        Frame frame, 
        EntityRef target, 
        FPVector2 hitDirection)
    {
        if (HitStatusEffects == null || HitStatusEffects.Length == 0)
            return;

        foreach (var statusEffectConfig in HitStatusEffects)
        {
            switch (statusEffectConfig.Type)
            {
                case StatusEffectType.Stun:
                    frame.Signals.OnStunApplied(target, statusEffectConfig.Duration);
                    break;

                case StatusEffectType.Knockback:
                    FPVector3 direction3D = new FPVector3(
                        hitDirection.X, 
                        hitDirection.Y, 
                        FP._0
                    );
                    frame.Signals.OnKnockbackApplied(
                        target, 
                        statusEffectConfig.Duration, 
                        direction3D
                    );
                    break;

                default:
                    throw new System.ArgumentException(
                        $"Unknown {nameof(StatusEffectType)}: {statusEffectConfig.Type}"
                    );
            }
        }
    }
}
```

## 使用方法

在 Unity Editor 中：

2. 配置参数：
   ```
   BaseDamage: 10
   KnockbackForce: 5
   HitstunDuration: 0.25
   AttackShape: Box (0.5, 0.5)
   ```


## 常见错误与解决

### ❌ 错误 1：重复命中
```csharp
// 错误：没有防重复命中机制
for (int i = 0; i < hits.Count; i++)
{
    ApplyDamage(frame, attacker, hits[i].Entity);
}
```

```csharp
// ✅ 正确：使用 HashSet 防重复
_hitEntities.Add(entityRef);
for (int i = 0; i < hits.Count; i++)
{
    if (_hitEntities.Contains(hits[i].Entity))
        continue;
    _hitEntities.Add(hits[i].Entity);
    ApplyDamage(frame, attacker, hits[i].Entity);
}
_hitEntities.Clear();
```

### ❌ 错误 2：错误的 Physics2D API
```csharp
// 错误
var filter = frame.Physics2D.OverlapShape(pos, rot, &shape);
while (filter.Next(frame, out var hit)) { }
```

```csharp
// ✅ 正确
HitCollection2D hits = frame.Physics2D.OverlapShape(
    transform->Position,
    transform->Rotation,
    shape,
    layerMask,
    QueryOptions.HitKinematics
);
for (int i = 0; i < hits.Count; i++) { }
```

### ❌ 错误 3：错误的执行时机
```csharp
// 错误：每帧都执行判定
if (abilityState.IsActive)
{
    PerformHitDetection();
}
```

```csharp
// ✅ 正确：只在激活帧执行判定
if (abilityState.IsActiveStartTick)
{
    OnAttackActivate(frame, entityRef, ref ability);
}
```

## 性能优化

1. **使用静态 HashSet**
   - 避免每次攻击都创建新集合
   - 记得使用后清空

2. **Layer Mask 过滤**
   - 只检测相关层级的物体
   - 通过 `GameSettingsData.PlayerLayerMask` 配置

3. **在正确的时机执行**
   - 只在 `IsActiveStartTick` 执行判定
   - 避免每帧重复检测
