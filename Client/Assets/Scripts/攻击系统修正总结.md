**❌ 之前的错误代码：**
```csharp
var hitFilter = frame.Physics2D.OverlapShape(
    attackPosition,
    attackRotation,
    &attackShape  // 错误：传递指针

while (hitFilter.Next(frame, out var hit))  // 错误：使用 StructList 模式
{
    // ...
}
```

**✅ 修正后的代码（基于官方示例）：**
```csharp
var shape = AttackShape.CreateShape(frame);
HitCollection2D hits = frame.Physics2D.OverlapShape(
    transform->Position,
    transform->Rotation,
    shape,  // 正确：直接传递 Shape2D
    gameSettingsData.PlayerLayerMask,  // Layer mask 过滤
    QueryOptions.HitKinematics
);

if (hits.Count > 0)
{
    for (int i = 0; i < hits.Count; i++)
    {
        Hit2D hit = hits[i];
        // 处理命中
    }
}
```

### 2. 防重复命中机制

**官方模式实现：**
```csharp
private static HashSet<EntityRef> _hitEntities = new HashSet<EntityRef>();

protected virtual void OnAttackActivate(Frame frame, EntityRef entityRef, Ability* ability)
{
    // ... 执行碰撞检测 ...
    
    if (hits.Count > 0)
    {
        // 添加攻击者自己
        _hitEntities.Add(entityRef);

        for (int i = 0; i < hits.Count; i++)
        {
            Hit2D hit = hits[i];

            // 跳过已经命中的实体
            if (_hitEntities.Contains(hit.Entity))
            {
                continue;
            }

            _hitEntities.Add(hit.Entity);
            
            // 处理命中...
        }

        // 清空集合，准备下次使用
        _hitEntities.Clear();
    }
}
```

### 4. 正确的执行时机

**官方模式：**
```csharp
public override Ability.AbilityState UpdateAbility(
    Frame frame, 
    EntityRef entityRef, 
    Ability* ability)
{
    Ability.AbilityState abilityState = base.UpdateAbility(frame, entityRef, ability);

    // 只在能力激活的第一帧执行攻击判定
    if (abilityState.IsActiveStartTick)
    {
        OnAttackActivate(frame, entityRef, ability);
    }

    return abilityState;
}
```

### 5. 队伍检测和格挡检测

**基于官方代码：**
```csharp
PlayerStatus* playerStatus = frame.Unsafe.GetPointer<PlayerStatus>(entityRef);
PlayerStatus* hitPlayerStatus = frame.Unsafe.GetPointer<PlayerStatus>(hit.Entity);

// 检查队伍
if (playerStatus->PlayerTeam == hitPlayerStatus->PlayerTeam)
{
    continue;  // 跳过队友
}

// 检查格挡
AbilityInventory* hitPlayerAbilityInventory = frame.Unsafe.GetPointer<AbilityInventory>(hit.Entity);
if (hitPlayerAbilityInventory->IsBlocking)
{
    frame.Events.OnPlayerBlockHit(hit.Entity, hitLateralDirection);
}
else
{
    // 应用伤害、击退、状态效果
}
```

### 6. 正确的方向计算

**2D 方向计算：**
```csharp
Transform2D* hitPlayerTransform = frame.Unsafe.GetPointer<Transform2D>(hit.Entity);

// 计算命中方向（2D）
FPVector2 hitLateralDirection = hitPlayerTransform->Position - transform->Position;
hitLateralDirection = hitLateralDirection.Normalized;

// 传递给事件

```

## 📊 3D vs 2D 对照表

| 项目 | 3D (官方示例) | 2D (您的项目) |
|------|---------------|---------------|
| **Shape Config** | `Shape3DConfig` | `Shape2DConfig` |
| **Transform** | `Transform3D*` | `Transform2D*` |
| **Physics API** | `Physics3D.OverlapShape` | `Physics2D.OverlapShape` |
| **Hit Collection** | `HitCollection3D` | `HitCollection2D` |
| **Hit Type** | `Hit3D` | `Hit2D` |
| **Vector** | `FPVector3` | `FPVector2`（内部转换为3D给信号） |
| **Position** | `transform->Position` (3D) | `transform->Position` (2D) |
| **Rotation** | `transform->Rotation` (Quaternion) | `transform->Rotation` (FP) |

## 🎯 完整的攻击流程

```
1. 玩家按下攻击键
   ↓
2. TryActivateAbility 检查是否可以激活
   - 检查能量消耗（指令技）
   - 检查冷却时间
   - 检查当前状态
   ↓
3. 激活成功，触发 OnPlayerAttacked 事件
   ↓
4. UpdateAbility 每帧调用
   ↓
5. IsActiveStartTick == true（激活的第一帧）
   ↓
6. OnAttackActivate 执行攻击判定
   ├─ 获取 PlayerStatus 和 Transform2D
   ├─ 创建攻击形状
   ├─ 执行 Physics2D.OverlapShape
   ├─ 遍历命中的实体
   │  ├─ 检查是否重复命中 (_hitEntities)
   │  ├─ 检查队伍
   │  ├─ 计算命中方向
   │  └─ 检查格挡
   │     ├─ 格挡：触发 OnPlayerBlockHit
   │     └─ 未格挡：
   │        ├─ ApplyDamage (扣除生命值)
   │        ├─ ApplyKnockback (施加击退)
   │        ├─ ApplyStatusEffects (应用状态效果)
   │        └─ 触发 OnPlayerHit 事件
   └─ 清空 _hitEntities
```

## ⚠️ 注意事项

1. **HashSet 是静态的**
   - 所有攻击共享同一个 `_hitEntities`
   - 必须在使用后清空：`_hitEntities.Clear()`

2. **使用 ref 还是指针**
   - `Ability` 在 `UpdateAbility` 中是指针：`Ability* ability`
   - `Ability` 在 `TryActivateAbility` 中是 ref：`ref Ability ability`

3. **Transform 获取**
   - 使用 `frame.Unsafe.GetPointer<Transform2D>(entityRef)`
   - 不要直接使用 `frame.Get<Transform2D>`

4. **Shape 创建**
   - 使用 `AttackShape.CreateShape(frame)` 创建 `Shape2D`
   - 不要传递指针 `&shape`

5. **Layer Mask**
   - 从 `GameSettingsData` 获取：`gameSettingsData.PlayerLayerMask`
   - 确保正确配置图层
